# Decodelab Internship — Sales Dashboard

## 📊 Project Overview

This project was completed as part of my Decodelab internship. The goal was to analyze sales and order data and develop an interactive dashboard using Microsoft Power BI.

The dashboard provides an overview of key sales performance indicators and allows users to understand revenue, orders, quantity sold, customer ordering patterns, and referral sources.

## 🛠️ Tools Used

* Microsoft Power BI
* Power Query
* Data Visualization
* Data Cleaning and Transformation
* DAX

## 📈 Dashboard KPIs

The dashboard highlights the following key performance indicators:

* Total Revenue: 1.26M
* Total Orders: 1.2K
* Total Quantity: 3.54K
* Average Order Value: 1,054

## 📊 Dashboard Visuals

The dashboard contains the following visualizations:

* Revenue by Product — compares revenue generated by different products.
* Revenue Trend Over Time — shows how revenue changes over time.
* Orders by Payment Method — shows the distribution of orders across payment methods.
* Orders by Referral Source — shows where customers were referred from.
* Revenue by Product Category — compares revenue across product categories.

## 🎯 Key Insights

The dashboard was designed to help identify:

* Products generating the highest revenue.
* Changes in revenue over time.
* The most commonly used payment methods.
* The referral sources contributing to orders.
* Product categories contributing significantly to overall revenue.
* Overall sales and ordering performance.

## 💡 Project Outcome

This project strengthened my practical skills in data cleaning, data visualization, dashboard development, Power BI, and business data analysis. It also provided an opportunity to transform raw data into an interactive and easy-to-understand business dashboard.
